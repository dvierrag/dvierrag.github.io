## Schematic

**Overview**

The system uses a 7805 linear regulator to convert the +9 V input into +5 V power which drives the PIC microcontroller and logic components. The H-Bridge enables the microcontroller to manage DC motor direction safely while the push-button functions as a user interface for system operation. The system includes indicator LEDs which help developers debug the system and display operational status. The design maintains stable references through ground connection unification.
