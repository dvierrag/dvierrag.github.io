Power Budget
---

**Overview**

A power budget serves as a planning document which details voltage and current requirements for all system components to verify that power supply and regulators can handle system loads safely. The power budget verifies that all system rails operate within safe limits while providing excess current capacity and confirms all components function properly under identical operating conditions.
