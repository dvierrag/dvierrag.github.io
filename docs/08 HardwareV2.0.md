**Version 2.0** 

The microcontroller section of my project uses the door sensor to detect changes and operates the H bridge motor controller for basic automated functionality. The microcontroller performs all logical operations by tracking sensor data and generating motor driver signals which activate the motor during door state transitions. The system requires power regulation to maintain stable voltage for both the board and driver components and motor and sensor and logic pin connections. The microcontroller functions as the main controller which reads current door conditions to generate motor commands that operate the door mechanism. The system connects all components through a defined control system which enables fast and dependable door condition responses.
